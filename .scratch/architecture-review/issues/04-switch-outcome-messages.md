# 04: 切換結果的訊息由命令列和視窗共用一份

**What to build:** `cc_quota_tracker/__main__.py` 的 `switch` 與 `cc_quota_tracker/widget.py` 的 `_check_switch` 各自把 `SwitchOutcome`（拒絕、寫了一半、驗證失敗、成功）× 切換或還原，對到語系檔的字串鍵。近期修切換訊息用字的 commit 都要兩處一起改。

方向：`fmt` 依切換結果、帳號標籤與語系產出訊息；命令列只決定印到 stdout 或 stderr、回什麼結束代碼，視窗只決定跳不跳對話框、要不要接著問還原。
