# 23: 字型設定，字型不存在時改用系統預設

**What to build:** 使用者可在設定檔指定介面字型；沒指定時用內建字型。不論內建或自填，字型在這台電腦上不存在時，一律改用系統預設字型，不讓 tk 自行替換成 Arial。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 設定檔新增 `font` 欄位，預設 `null`；第一次啟動寫出的完整設定檔包含它（spec〈路徑與設定檔〉）
- [ ] 只能在設定檔調整，不進右鍵選單；依修改時間重讀，改了下一輪就生效
- [ ] `null`：使用設計 token 的內建字型；填入字型家族名稱：所有文字改用它，字級與字重仍取自 token
- [ ] 字型不存在（內建或自填）時改用 `TkDefaultFont` 的字型家族，不讓 tk 自行替換
- [ ] 值不是字串也不是 `null`：照「單一欄位不合法」處理，那一欄用預設並在提示列出欄位名
- [ ] 換字型只改既有 item 的字型屬性，不重建；縫 ②：來回切換字型，item 數不變
- [ ] 實作前與使用者確認：自填的字型不存在時，要不要在看板提示（字型存不存在只有畫面層知道，與「要不要警示由核心決定」的判準要一起考慮）
