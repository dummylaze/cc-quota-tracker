# 09: 綁定維護：直接放檔、改檔名、清理殘留

**What to build:** 讓使用者不透過 `add`，直接把憑證檔放進納管目錄或改檔名，也能被正確納管與維持身分綁定；刪檔後工具自己的殘留資料自動清掉。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 直接放進目錄、還沒有綁定的憑證快照，要同時符合三條件才補學綁定：它是使用中帳號、額度快取的識別碼與 `oauthAccount` 的識別碼一致、該識別碼尚未綁給其他帳號
- [ ] 條件不符時不補學，該帳號維持「讀數待更新」，不猜測
- [ ] 綁定以身分鍵為鍵，改憑證快照檔名後綁定仍然保留
- [ ] 憑證快照被刪除後，對應的孤兒綁定自動清除
- [ ] 以縫 ① 的測試涵蓋：改檔名後綁定仍在、三條件缺一不補學
