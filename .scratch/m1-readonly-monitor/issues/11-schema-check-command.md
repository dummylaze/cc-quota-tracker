# 11: 架設者檢查指令

**What to build:** 架設者可以執行一個檢查指令，確認工具依賴的欄位路徑在自己機器的額度快取裡仍然存在、型別正確，並列出 `utilization` 底下新出現的未知欄位，用來在 Claude Code 改版後快速判斷相容性。

**Blocked by:** 03, 21

**Status:** resolved

- [x] 命令列入口下有這個檢查子命令
- [x] 逐一驗證工具依賴的欄位路徑存在、型別正確，並清楚標示通過與否
- [x] 列出 `utilization` 底下不在已知清單內的欄位
- [x] 輸出不含帳號識別碼或 email
- [x] 唯讀，不寫入任何 Claude Code 維護的檔案
- [x] 印出實際使用的 Claude Code 目錄與納管目錄，各自註明來自設定檔、環境變數或預設值

## Comments
