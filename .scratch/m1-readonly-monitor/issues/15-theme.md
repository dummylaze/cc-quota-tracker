# 15: 主題：跟隨系統、淺色、深色

**What to build:** 使用者可選跟隨系統、淺色或深色；選跟隨系統時，Windows 切換應用程式深淺色，視窗也跟著變。切換主題只改屬性，不重建畫面物件。

**Blocked by:** 13, 14

**Status:** resolved

- [x] 右鍵選單加主題項，預設跟隨系統
- [x] 跟隨系統時讀取 Windows 的應用程式深淺色設定，每輪 poll 檢查一次
- [x] 嚴重度配色在淺色與深色下都清楚可辨
- [x] 切換主題只改既有 item 的屬性；縫 ②：淺色與深色來回切換 N 次，回到同一狀態時 item 數相同
- [x] 顏色只在設計 token 中定義

## Comments

- 2026-09-29：完成。
  - **系統深淺色**：讀 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` 的 `AppsUseLightTheme`，0 為深色；讀不到（舊版 Windows、非 Windows）當淺色。每次渲染都讀一次，所以每輪 poll 都會檢查；從選單改偏好時也會多讀一次。
  - **「清楚可辨」的判準**：採 WCAG 2.1 SC 1.4.11，嚴重度色對它畫在上面的顏色（卡片底色、進度條底軌）對比至少 3:1，三種嚴重度的顏色互不相同；由 token 測試守住。
  - **配色調整**：淺色主題的 normal 由 `#2e9d5b` 改為 `#2a9254`、warning 由 `#c99500` 改為 `#a17900`，原值在底軌上只有約 2.6:1。另外比較過「底軌調淡」，那會讓空底軌在白卡片上幾乎看不見，使用者看過三者並排後選了調深嚴重度色。深色主題原本就達標，沒動。
  - 百分比數字是 13pt 粗體，略小於 WCAG 的大字門檻（14pt 粗體），照字面應是 4.5:1；調整後對白卡片約 4.0:1，沒有另外處理。
  - 右鍵選單是原生選單，不跟主題變色。
