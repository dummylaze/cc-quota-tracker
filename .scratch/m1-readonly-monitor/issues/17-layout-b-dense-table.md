# 17: 版面 B：密集表格與單行條，加入版面切換

**What to build:** 使用者可在右鍵選單切換版面，選 B 時：精簡模式是一行橫條，展開模式是一列一個帳號的表格。這一票同時建立版面切換的機制，舊版面的物件要整批銷毀。B 是獨立的渲染器，不與 A 共用版面程式碼。

**Blocked by:** 13, 14

**Status:** ready-for-agent

- [ ] 右鍵選單加版面項：A 卡片列表（預設）、B、C（C 尚未實作時不出現在選單）
- [ ] B 精簡模式：一行橫條，含帳號標籤、兩個窗口的小進度條與百分比、讀數年齡、提示數量
- [ ] B 展開模式：表格一列一個帳號，欄位為工作階段窗口、週窗口、讀數年齡、憑證到期倒數；提示接在該列下方；使用中帳號那一列加淡色底
- [ ] 視覺風格與 token 沿用，版面不寫死數值
- [ ] 同一時間只建立目前選用的版面；切換時舊版面物件整批銷毀
- [ ] 縫 ②：B 版跑精簡／展開、淺色／深色來回切換；A 與 B 來回切換 N 次，回到同一版面時 item 數相同

## Comments
- 2026-09-29：「憑證到期天數」改為「憑證到期倒數」：兩個單位＋絕對時間，格式依設定（票 08 後續，見 spec〈核心與看板〉的倒數格式）。
