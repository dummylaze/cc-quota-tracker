# 17: 版面 B：密集表格與單行條，加入版面切換

**What to build:** 使用者可在右鍵選單切換版面，選 B 時：精簡模式是一行橫條，展開模式是一列一個帳號的表格。這一票同時建立版面切換的機制，舊版面的物件要整批銷毀。B 是獨立的渲染器，不與 A 共用版面程式碼。

**Blocked by:** 13, 14, 22

**Status:** resolved

- [x] 右鍵選單加版面項：A 卡片列表（預設）、B、C（C 尚未實作時不出現在選單）
- [x] B 精簡模式：一行橫條，含帳號標籤、兩個窗口的小進度條與百分比、讀數年齡、提示數量
- [x] B 展開模式：表格一列一個帳號，欄位為工作階段窗口、週窗口、讀數年齡、憑證到期倒數；提示接在該列下方；使用中帳號那一列加淡色底
- [x] 視覺風格與 token 沿用，版面不寫死數值
- [x] 同一時間只建立目前選用的版面；切換時舊版面物件整批銷毀
- [x] 縫 ②：B 版跑精簡／展開、淺色／深色來回切換；A 與 B 來回切換 N 次，回到同一版面時 item 數相同

## Comments
- 2026-09-29：「憑證到期天數」改為「憑證到期倒數」：兩個單位＋絕對時間，格式依設定（票 08 後續，見 spec〈核心與看板〉的倒數格式）。
- 2026-09-29：加上被票 22 擋住：B 沿用同一組 token，先依 spec〈畫面層〉的配色規則修好 token 再做（使用者決定）。
- 2026-09-29：使用中列的淡色底與配色規則衝突：淺色的嚴重度三色對白卡片剛好 4.5:1，任何淡色底都會讓它們跌破；APCA 對這麼淡的底色直接判 Lc 0，也過不了「看得見 ≥ Lc 15」。給了「淡色底＋加深」與「accent 外框、無底色」兩張並排截圖，使用者選淡色底＋加深：淺色 `active_row` `#f5f7fd`，normal／warning／critical 調為 `#118246`／`#916c00`／`#cd3c3e`（A 同步）；深色 `active_row` `#1e2130`（比卡片暗，提亮會讓 sub 與嚴重度文字跌破 Lc 60）。淡色底對卡片、空底軌對淡色底兩項列為規則例外，寫進 spec〈畫面層〉。
- 2026-09-29：實作備註：提示與橫幅的文案、折行抽到 `canvas_text.py` 給 A、B 共用（文案不是版面程式碼，票 16 的語系也要集中）；B 的繪製輔助（圓角、進度條、item 池）照 spec 另寫一份。表格裡只是告知到期時間的提示不再重複列出（已在「憑證到期」欄），要使用者動手的到期提示照列。單行條與表格都不顯示窗口的重置倒數：B 的欄位清單沒有它；spec 使用者故事 3 要求「每個窗口的重置倒數」，要 B 也滿足的話另開票。
