# 05: 納管帳號：憑證儲存、add／remove 與命令列入口

**What to build:** 使用者在 Claude Code 登入某帳號後，用命令列執行 `add <標籤>` 就把該帳號納管，`remove <標籤>` 移除，`list` 看結果。`add` 當下就綁定該帳號的識別碼，並把存放憑證快照的目錄與檔案收緊到只有目前使用者能讀。這一票同時定義命令列的唯一入口，讓 README 與畫面上的提示都能引用完整寫法。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 憑證儲存介面提供讀取、身分鍵、內容雜湊三個方法，不回傳 token 本身；只實作檔案版本
- [ ] 身分鍵是 refreshToken 雜湊的前 16 個十六進位字元；內容雜湊排除 accessToken 與到期時間，絕不對整份檔案雜湊
- [ ] 帳號鍵格式為「供應商前綴:標籤」，標籤就是憑證快照的檔名去掉副檔名
- [ ] 命令列有單一入口，以 `python -m <套件名> <子命令>` 執行，純標準庫；子命令為 add、remove、list；完整寫法記在 README 與未納管卡片可引用的一處
- [ ] `add`：複製當前憑證成為憑證快照，綁定當下的 `oauthAccount` 識別碼；標籤已存在就覆寫（重新納管走這條）
- [ ] `add` 主動收緊權限（Windows 移除繼承、只授權目前使用者），事後驗證，不符就修正並告警；在 Windows 真實暫存目錄上驗證
- [ ] 標籤看起來像 email 時提示「這會顯示在畫面上」
- [ ] `remove`：刪除憑證快照並清掉工具自己的綁定
- [ ] 工具狀態寫入一律原子寫入：暫存檔建在目標同一目錄、帶明確前綴、權限錯誤重試 3 次每次 50 ms、失敗清掉殘留
- [ ] 核心的 add／remove 是 GUI 也會呼叫的同一組操作，介面不依賴命令列
- [ ] 本工具不讀取也不儲存 email；不寫入 Claude Code 維護的任何檔案
