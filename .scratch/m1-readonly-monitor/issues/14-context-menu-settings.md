# 14: 右鍵選單、設定持久化與視窗行為

**What to build:** 使用者在視窗上按右鍵，就能直接調整各項設定並管理帳號，不必再開設定視窗；設定與視窗位置在重新啟動後保留。GUI 也能納管帳號：一個是納管目前登入的帳號，一個是匯入憑證檔。

**Blocked by:** 05, 12

**Status:** ready-for-agent

- [ ] 選單設定項：置頂（開關，預設開）、模式（精簡／展開，雙擊視窗也能切換）、透明度（100／85／70%）；切換立即生效、不跳確認
- [ ] 選單動作：開啟納管目錄、結束
- [ ] 「納管目前登入的帳號…」：跳出標籤輸入框，呼叫核心的 add，行為與命令列相同（含 email 標籤提示、權限收緊）
- [ ] 「匯入憑證檔…」：選一個憑證檔複製進納管目錄，標籤預設取檔名去掉副檔名；同樣收緊權限；綁定沿用 ticket 09 的補學規則，不在此另做判斷
- [ ] 設定（置頂、模式、語系、主題、透明度、版面）寫入工具狀態並在重啟後保留；設定只能從 GUI 修改
- [ ] 視窗位置自動記住；上次位置已不在任何螢幕內時回到主螢幕
- [ ] 固定值不開放設定：輪詢間隔 5 秒、百分比門檻、到期警示天數
- [ ] 版面、語系、主題、開機自動啟動的選單項由各自的票加入
- [ ] 常駐一整天記憶體不持續上升
