# 14: 右鍵選單、設定持久化與視窗行為

**What to build:** 使用者在視窗上按右鍵，就能直接調整各項設定並管理帳號，不必再開設定視窗；設定與視窗位置在重新啟動後保留。GUI 也能納管帳號：一個是納管目前登入的帳號，一個是匯入憑證檔。

**Blocked by:** 05, 12, 21

**Status:** resolved

- [x] 選單設定項：置頂（開關，預設開）、模式（精簡／展開，雙擊視窗也能切換）、透明度（100／85／70%）；切換立即生效、不跳確認
- [x] 選單動作：開啟納管目錄、結束
- [x] 「納管目前登入的帳號…」：跳出標籤輸入框，呼叫核心的 add，行為與命令列相同（含 email 標籤提示、權限收緊）
- [x] 「匯入憑證檔…」：選一個憑證檔複製進納管目錄，標籤預設取檔名去掉副檔名；同樣收緊權限；綁定沿用 ticket 09 的補學規則，不在此另做判斷
- [x] 設定（置頂、模式、語系、主題、透明度、版面）寫入設定檔（ADR-0008）並在重啟後保留；GUI 是主要入口，也可手改設定檔
- [x] 偏好每一輪依設定檔修改時間重讀，手改後不必重啟就生效
- [x] GUI 寫入時先重讀設定檔、只改那一欄、再原子寫入，不蓋掉使用者剛手改的內容
- [x] 設定檔整個不是合法 JSON：偏好全用預設並提示，GUI 改動只在記憶體生效、不寫回；單一偏好值不合法：只那一欄用預設，提示列出欄位名
- [x] 視窗位置自動記住，存在納管目錄的工具狀態、不進設定檔；上次位置已不在任何螢幕內時回到主螢幕
- [x] 固定值不開放設定：輪詢間隔 5 秒、百分比門檻、到期警示天數
- [x] 版面、語系、主題、開機自動啟動的選單項由各自的票加入
- [x] 常駐一整天記憶體不持續上升

## Comments

- 2026-09-28：依 ADR-0008 改寫。原本「設定寫入工具狀態、只能從 GUI 修改」改為設定另存設定檔、可手改；新增重讀、合併寫入與不合法值三條；視窗位置維持工具狀態。設定檔的建立、路徑欄位與路徑解析屬於票 21，本票只處理偏好。固定值那條不變。
- 2026-09-29：新增「倒數格式」設定項（`countdownFormat`，票 08 後續，見 spec〈核心與看板〉）；設定檔欄位與核心讀取已做，本票只做選單項目與寫回。
- 2026-09-29：右鍵選單不能變長（使用者決定，見 spec〈畫面層〉）。設定檔新增的 `providers`（憑證到期警示天數、百分比門檻）只放設定檔，不進選單。
- 2026-09-29：「倒數格式」從選單設定項拿掉（使用者決定，右鍵選單不能變長），只能在設定檔調整；取代上面新增它的那一則。
- 2026-09-29：完成。
  - **核心多一個操作 `import_snapshot(憑證檔, 標籤)`**：匯入要跟 add 一樣驗證憑證、收緊權限，這些都在核心裡，所以沒有在畫面層另寫一份。它不決定綁定：同一憑證指紋原有的綁定照樣有效，沒有的話由 poll 依直接放檔的規則補學。spec〈核心與看板〉「對外只提供三個操作」要不要改寫，待使用者決定。
  - **偏好走看板**：核心本來就依修改時間重讀設定檔，看板多帶 `preferences` 與 `invalid_settings`，視窗每輪從看板取值套用。
  - **不合法值的提示**：只涵蓋六項偏好與 `countdownFormat`。`providers` 底下的值不合法時照舊靜默用預設。
  - **行為修正**：設定檔讀不懂時，倒數格式與 `providers` 原本沿用上一次讀到的值，現在依 spec「全部使用預設值」一起回到預設。
  - **GUI 寫入的兩種失敗分開處理**：設定檔讀不懂時，改動只在記憶體生效，修好後以設定檔為準；設定檔讀得懂但寫不進去（例如被防毒鎖住）時，每輪 poll 前重試，寫進去為止。
  - **視窗位置**：存在工具狀態的 `window.json`，只在拖動放開與結束時、位置有變才寫。判斷是否在螢幕內看的是視窗左上角往內 20px 那一點；Windows 用作業系統的多螢幕判斷。
  - **雙擊**：在摺疊區標題上雙擊不再切換模式（票 13 的已知限制）。
  - **匯入時標籤已存在**：會先問是否取代，標籤比對不分大小寫。「納管目前登入的帳號…」與命令列 add 一樣直接覆寫，不問。
  - **記憶體**：自動測試只確認每輪不累積 Tcl 變數、item 與 `after`。一整天的實測依 spec〈測試決策〉在票 20 手動驗收。
  - **主題**：選「跟隨系統」時暫時一律顯示淺色，由票 15 接手。
- 2026-09-29：使用者同意四項建議：spec〈核心與看板〉改為四個操作（加上 import），看板的全域狀態補上偏好與不合法欄位；匯入撞名時保留確認；`providers` 的不合法值暫不提示；記憶體實測留在票 20。
