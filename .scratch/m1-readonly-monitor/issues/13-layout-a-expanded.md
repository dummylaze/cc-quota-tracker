# 13: 版面 A 展開模式

**What to build:** 展開模式顯示每個納管帳號的卡片，使用中帳號高亮，待命帳號顯示最後觀測的讀數與相對年齡；使用中帳號多出週窗口起訖進度、用量去向、模型週限額、額外用量與花費，其餘限額放在摺疊區以原始名稱顯示；各種提示與異常狀態都有對應的呈現。

**Blocked by:** 06, 12

**Status:** resolved

- [x] 每個納管帳號一張卡片；使用中帳號高亮，並帶「使用中／待命」標籤
- [x] 待命帳號顯示觀測讀數與相對年齡，不掛警示
- [x] 使用中帳號展開專用資料：週窗口起訖進度、用量去向、模型週限額、額外用量、花費；沒有或未啟用就不占版面
- [x] 其他限額放摺疊區，以供應商原始名稱顯示
- [x] 提示前有嚴重度色點；鎖定原因用紅字
- [x] 顯示狀態：讀數待更新（含說明）、尚無讀數、落後讀數提示、憑證快照已失效、憑證到期警示與補救步驟、結構變更橫幅（含最後成功讀數與時間）
- [x] 未納管帳號卡片寫明納管方法，內容包含 ticket 05 定義的命令列完整寫法，以及右鍵選單「納管目前登入的帳號…」的路徑
- [x] 精簡模式不建立展開模式的 widget，展開模式的 widget 延遲建立
- [x] 縫 ②：精簡與展開來回切換 N 次，回到同一模式時 item 數相同

## Comments

- 2026-09-29：完成。版面 A 的 `render` 多一個 `expanded` 參數；視窗暫以雙擊切換模式（選單項屬票 14），切換時以上一輪的看板重畫、不另外 poll。卡片與變長清單（範圍週限額、用量去向、其他限額）由 pool 補建或刪到剛好的數量，所以 item 數只由看板、模式與摺疊區開合決定，不再是票 12 的「所有看板狀態恆定」。展開專用的 item 只建在使用中帳號（或未納管帳號）那張卡片上，回到精簡模式就刪掉。提示列（讀數說明、未納管的納管方法、落後、鎖定、憑證快照）在精簡模式也顯示。週窗口起訖進度取自用量去向的起訖時間，沒有用量去向就不顯示。結構變更橫幅之外，設定檔無法讀取、路徑欄位改了需重新啟動、疑似讀錯位置也放進同一個橫幅。其他限額的摺疊區點標題開合，開合狀態不保存。已知限制：在摺疊區標題上雙擊，會開合兩次（等於沒變），同時切換精簡／展開，因為標題的點擊綁定與視窗的雙擊綁定會一起觸發；雙擊的正式行為屬票 14，屆時一併處理。
