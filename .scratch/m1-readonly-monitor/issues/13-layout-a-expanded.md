# 13: 版面 A 展開模式

**What to build:** 展開模式顯示每個納管帳號的卡片，使用中帳號高亮，待命帳號顯示最後觀測的讀數與相對年齡；使用中帳號多出週窗口起訖進度、用量去向、模型週限額、額外用量與花費，其餘限額放在摺疊區以原始名稱顯示；各種提示與異常狀態都有對應的呈現。

**Blocked by:** 06, 12

**Status:** ready-for-agent

- [ ] 每個納管帳號一張卡片；使用中帳號高亮，並帶「使用中／待命」標籤
- [ ] 待命帳號顯示觀測讀數與相對年齡，不掛警示
- [ ] 使用中帳號展開專用資料：週窗口起訖進度、用量去向、模型週限額、額外用量、花費；沒有或未啟用就不占版面
- [ ] 其他限額放摺疊區，以供應商原始名稱顯示
- [ ] 提示前有嚴重度色點；鎖定原因用紅字
- [ ] 顯示狀態：讀數待更新（含說明）、尚無讀數、落後讀數提示、憑證快照已失效、憑證到期警示與補救步驟、結構變更橫幅（含最後成功讀數與時間）
- [ ] 未納管帳號卡片寫明納管方法，內容包含 ticket 05 定義的命令列完整寫法，以及右鍵選單「納管目前登入的帳號…」的路徑
- [ ] 精簡模式不建立展開模式的 widget，展開模式的 widget 延遲建立
- [ ] 縫 ②：精簡與展開來回切換 N 次，回到同一模式時 item 數相同
