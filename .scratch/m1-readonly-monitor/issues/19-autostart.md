# 19: 開機自動啟動

**What to build:** 使用者可在右鍵選單開關「開機自動啟動」，登入 Windows 後就不必手動啟動視窗。

**Blocked by:** 14

**Status:** resolved

- [x] 右鍵選單加此開關，預設關閉
- [x] 開啟時，在目前使用者的登入啟動項寫入本工具自己的一個值，以 `pythonw` 啟動；關閉時移除
- [x] 只改動本工具自己的那一個值，用標準庫操作
- [x] 開關的顯示狀態以登錄的實際值為準，不另存一份
- [x] 不動到 Claude Code 的任何設定
- [x] 實機驗證（列入 ticket 20 手動驗收）：重新登入後視窗自動出現；關閉後登錄值已移除

## Comments

- 2026-09-29：完成，最後一項實機驗收（重新登入後視窗自動出現）留在票 20。
  - **啟動命令不用 `-m`**：登入時的工作目錄不是專案根目錄，而專案是原始碼部署、沒有安裝進 site-packages，`pythonw -m cc_quota_tracker gui` 在開機時找不到套件。改成 `pythonw -c "…sys.path.insert(0, 專案根目錄)…main(['gui'])"`，路徑的空白與引號交給標準庫處理。測試用真的子行程在別的工作目錄照登錄寫法執行一次，路徑含空白與單引號也驗過。
  - **「開」的判準是登錄值等於現在這份程式的命令**，不只是值存在。專案搬家或換了 Python 之後，舊的啟動項開機時啟動不了，顯示成開會讓使用者以為沒問題；顯示成關、再開一次就改寫成正確的。這比 ticket 字面（值存在即開）多做一步，待使用者確認。
  - **勾選狀態每次開選單前問登錄**，不存也不快取；寫入失敗時跳錯誤對話框，勾選回到登錄的實際值。
  - **只支援 Windows**：其他平台選單不放這一項。
  - 測試的登錄操作寫在測試專用的暫存機碼、測完刪除，不碰真實的啟動項。
- 2026-10-01：最後一項的實機驗收已在票 20 完成（見票 20 的 2026-09-30 Comments），回頭勾選。
