# 19: 開機自動啟動

**What to build:** 使用者可在右鍵選單開關「開機自動啟動」，登入 Windows 後就不必手動啟動視窗。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 右鍵選單加此開關，預設關閉
- [ ] 開啟時，在目前使用者的登入啟動項寫入本工具自己的一個值，以 `pythonw` 啟動；關閉時移除
- [ ] 只改動本工具自己的那一個值，用標準庫操作
- [ ] 開關的顯示狀態以登錄的實際值為準，不另存一份
- [ ] 不動到 Claude Code 的任何設定
- [ ] 實機驗證（列入 ticket 20 手動驗收）：重新登入後視窗自動出現；關閉後登錄值已移除
