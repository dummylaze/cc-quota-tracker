# 22: 依配色規則修正 token，並補行高、同心圓角：深色對比、借用角色、一色一義

**What to build:** 讓現有 token 符合 spec〈畫面層〉的配色規則：深色主題下空的進度條底軌、附註小字與 critical 數值都看得清楚；每個 token 只用在自己的角色；`accent` 只代表使用中帳號。多行附註的行距拉開，巢狀圓角同心。規則中可機械判定的部分寫成 token 測試，版面 B、C 沿用同一組 token 時就不會再踩到。

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] 待命標籤的底色不再借用進度條底軌的 `track`，改用自己的 token（[layout_a.py](../../../cc_quota_tracker/layout_a.py) 的 `_header`）
- [ ] 週窗口已過 %、額外用量這類中性進度條不再用 `accent`，改用中性的 token；`accent` 只留給使用中帳號的外框、使用中標籤、未納管提示
- [ ] 深色主題：空底軌對卡片 |Lc| ≥ 15；附註小字（`sub`）與三種嚴重度數值對卡片 |Lc| ≥ 60；調整時保持色相、只動明度
- [ ] 兩套主題的每一組「前景＋它實際畫在上面的底色」都符合 spec 的 WCAG 下限與 APCA 目標；token 測試列出這些組合，逐一檢查兩套標準
- [ ] 待命標籤的文字對它的底色 ≥ 4.5:1（8pt 是一般文字；目前兩種主題都是 4.04:1）
- [ ] 多行文字（附註、提示、橫幅）的行高 ≥ 1.5：tk 的 canvas 文字沒有行距選項，目前固定是字型的 linespace（1.25～1.31）。要拆成逐行 item 自己排；逐行 item 的數量跟著換行變，照 `_Pool` 的規則補建或刪到剛好，縫 ② 不受影響
- [ ] 巢狀圓角同心：外層圓角＝內層圓角＋兩者之間的內距（目前 panel 16，card 12＋`panel_pad` 12＝24）；改外層或改內層是視覺取捨，給並排截圖選
- [ ] 修改前後的淺色與深色並排截圖給使用者確認後才定案（視覺取捨不以文字選）
- [ ] 縫 ②：主題與模式來回切換，item 數不變（既有測試照樣通過）
