# 22: 依配色規則修正 token，並補行高、同心圓角：深色對比、借用角色、一色一義

**What to build:** 讓現有 token 符合 spec〈畫面層〉的配色規則：深色主題下空的進度條底軌、附註小字與 critical 數值都看得清楚；每個 token 只用在自己的角色；`accent` 只代表使用中帳號。多行附註的行距拉開，巢狀圓角同心。規則中可機械判定的部分寫成 token 測試，版面 B、C 沿用同一組 token 時就不會再踩到。

**Blocked by:** 15

**Status:** resolved

- [x] 待命標籤的底色不再借用進度條底軌的 `track`，改用自己的 token（[layout_a.py](../../../cc_quota_tracker/layout_a.py) 的 `_header`）
- [x] 週窗口已過 %、額外用量這類中性進度條不再用 `accent`，改用中性的 token；`accent` 只留給使用中帳號的外框、使用中標籤、未納管提示
- [x] 深色主題：空底軌對卡片 |Lc| ≥ 15；附註小字（`sub`）與三種嚴重度數值對卡片 |Lc| ≥ 60；調整時保持色相、只動明度
- [x] 兩套主題的每一組「前景＋它實際畫在上面的底色」都符合 spec 的 WCAG 下限與 APCA 目標；token 測試列出這些組合，逐一檢查兩套標準
- [x] 待命標籤的文字對它的底色 ≥ 4.5:1（8pt 是一般文字；目前兩種主題都是 4.04:1）
- [x] 多行文字（附註、提示、橫幅）的行高 ≥ 1.5：tk 的 canvas 文字沒有行距選項，目前固定是字型的 linespace（1.25～1.31）。要拆成逐行 item 自己排；逐行 item 的數量跟著換行變，照 `_Pool` 的規則補建或刪到剛好，縫 ② 不受影響
- [x] 巢狀圓角同心：外層圓角＝內層圓角＋兩者之間的內距（目前 panel 16，card 12＋`panel_pad` 12＝24）；改外層或改內層是視覺取捨，給並排截圖選
- [x] 修改前後的淺色與深色並排截圖給使用者確認後才定案（視覺取捨不以文字選）
- [x] 縫 ②：主題與模式來回切換，item 數不變（既有測試照樣通過）

## Comments

- 2026-09-29：開票依據是票 15 收尾時，以配色規則實測現有 token 的結果（尚未修改任何 token）：
  - 深色 `track` 對 `card`：WCAG 1.33:1，APCA 低於 Lc 15，幾乎看不見
  - 深色 `sub` 對 `card`：WCAG 5.4:1 合格，但 APCA 只有 Lc 45（淺色是 Lc 76）
  - 深色 critical 對 `card`：Lc 46
  - 待命標籤的底色借用 `track`
  - `accent` 同時用於使用中外框、使用中標籤、週窗口進度條、額外用量進度條、未納管提示的色點
  - 淺色主題的主要文字都已達到 APCA 目標
- 2026-09-29：併入行高、同心圓角、待命標籤對比三項（使用者決定）。來源是審美驗證的基準線量測：留白率 62～69%（下限 35%，通過）、多行文字行高 1.25／1.31、panel 圓角 16 對 card 12＋內距 12、待命標籤文字 4.04:1。
- 2026-09-29：完成。
  - **量法**：`tests/test_tokens.py` 列出每一組「前景＋它實際畫在上面的底色」與門檻，兩套主題各量 WCAG 2 對比與 APCA Lc（APCA-W3 0.0.98G，對照參考值測過）。門檻分三級：文字 4.5:1／Lc 60、圖形 3:1／Lc 30、只要看得見 Lc 15。百分比是 13pt 粗體，未達大字門檻，照一般文字算。
  - **調色**：只調 OKLCH 明度、保持色相，取剛好過門檻的最小調整。淺色：normal `#1a874a`、warning `#967105`、critical `#d34243`（票 15 的配色對白卡片只有 3.9～4.4:1，照 spec 要 4.5:1；另一條路是百分比改 14pt，使用者選調深）。深色：底軌 `#5a5a60`、`sub` `#b6b6be`、normal `#54cc86`、critical `#fe9b97`、`accent` `#89affe`（讓使用中標籤文字達 Lc 60）。深色 critical 提亮後偏粉，使用者看過截圖後接受。
  - **新角色**：`neutral`（週窗口已過 %、額外用量的進度條）、`chip_standby`／`chip_standby_fg`（待命標籤）；`chip_fg` 改名 `chip_active_fg`。
  - **行高**：`LINE_HEIGHT = 1.5`。附註、提示、橫幅、用量去向的名稱自己折行（西文在字間斷、中日韓字元逐字斷），逐行一個 item；各行保留行尾空白，接回去就是原文。「本週用量去向」與摺疊區標題是單行標題，沒改。
  - **圓角**：實作中發現 `rrect` 用 tk 的 smooth 多邊形，曲線只經過相鄰兩點的中點，畫出的半徑只有 token 的一半（token 16／12，實畫約 8／6），拿 token 算同心沒有意義。改成以折線逼近四分之一圓，實測 45° 方向缺口與理論值差 0.3px。副作用：標籤（radius 9、高 18）變成完整膠囊形。同心方案給了 24／12、16／4、18／6 三組並排截圖，使用者選 panel 18／card 6（最接近原本實際看到的樣子）。
