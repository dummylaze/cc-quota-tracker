# 06: 使用中帳號判定與讀數歸屬

**What to build:** 讓看板分辨誰是使用中帳號，並把每份用量讀數歸屬給正確的帳號：切換後不會把舊帳號的數字掛在新帳號名下；還沒有該帳號的讀數時明確顯示「讀數待更新」；登入了還沒納管的帳號時出現未納管帳號卡片；待命帳號顯示最後觀測到的讀數與相對年齡，不因為舊而警示。

**Blocked by:** 01, 05

**Status:** resolved

- [x] 當前憑證的憑證指紋對上某份憑證快照 → 該帳號是使用中帳號；對不上 → 使用中帳號是未納管帳號
- [x] 讀數只在額度快取的識別碼等於該帳號綁定的識別碼時才歸屬；使用中帳號沒有屬於它的讀數 → 讀數待更新，並帶說明「Claude Code 更新額度快取後就會出現」
- [x] 切換後第一輪就判對使用中帳號，舊帳號的讀數不會歸給新帳號
- [x] 未納管帳號卡片的內容包含納管方法（引用 ticket 05 定義的命令列完整寫法）
- [x] 待命帳號顯示最後一次觀測的讀數與相對年齡（例如「3 天前」）；不因讀數舊而警示；讀數是觀測值，只有在觀測後沒被用過才準確
- [x] 使用中帳號的讀數年齡在看板中可取得
- [x] 以縫 ① 的測試涵蓋：切換第一輪、舊讀數不歸新帳號、憑證指紋對不上任何快照
