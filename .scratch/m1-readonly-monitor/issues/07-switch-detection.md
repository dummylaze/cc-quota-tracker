# 07: 切換偵測狀態機與工具狀態

**What to build:** 讓工具每一輪都能判斷「這是刷新、切換，還是憑證快照失效」，並把觀測到的切換與自己最後一次運作時間記下來，供日後報表使用。任何情況下都不改寫憑證快照或 Claude Code 的檔案。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 憑證指紋不變（刷新或無變化）→ 不記錄
- [ ] 憑證指紋改變且對上某份憑證快照 → 切換，追加一行切換紀錄（時間、帳號識別碼、來源為觀測）；帳號識別碼取該快照綁定的值
- [ ] 切換紀錄不記帳號鍵：改憑證快照檔名前後的切換紀錄，帳號識別碼相同（ADR-0009）
- [ ] 切到未納管帳號時，帳號識別碼取 `oauthAccount` 的識別碼；拿不到時仍追加一行，帳號識別碼為 `null`
- [ ] 切換紀錄放在納管目錄的工具狀態裡，權限與綁定同樣收緊
- [ ] 憑證指紋改變、對不上任何快照、但 `oauthAccount` 識別碼仍等於前一個使用中帳號的綁定 → 該帳號卡片標記「憑證快照已失效，請重新納管」，憑證快照檔案內容不變
- [ ] 其他情況 → 切換到未納管帳號，同樣追加切換紀錄
- [ ] 切換紀錄只追加，不改舊行
- [ ] 每一輪更新最後運作時間
- [ ] 多輪 poll 之後，額度快取檔與 Claude Code 設定檔的修改時間都不變
- [ ] 若 ticket 01 的結論推翻了原假設，先與使用者確認判定方式再實作
