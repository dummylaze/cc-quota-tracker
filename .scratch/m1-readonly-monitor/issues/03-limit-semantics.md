# 03: 限額語意補齊

**What to build:** 讓看板正確表達每一種限額的狀態：沒有計時中窗口時顯示「無計時中窗口」而不是 0%；嚴重度以供應商為準；不認得的限額以原始名稱呈現；額外用量、花費、模型週限額和週窗口用量去向在有值或啟用時才帶出。

**Blocked by:** 02

**Status:** resolved

- [x] 限額沒有重置時間，或現在時間已到該限額自己的重置時間 → 「無計時中窗口」，重置時間標為未知，不推算下一個重置時間（原寫「標記為不活躍」：實測 `is_active` 是頭條列，不是窗口開關，已改，見 spec〈補充說明〉）
- [x] 嚴重度以供應商給的值為主；不認得的值當 `normal`；欄位缺失才退回百分比門檻（0–60 綠、60–85 黃、85–100 紅）
- [x] 帳號額度被鎖定時，看板帶出鎖定原因
- [x] 不認得的限額種類，以及 `utilization` 底下形狀符合但不在已知清單內的欄位，都歸入其他限額並保留原始名稱
- [x] 範圍週限額（含模型週限額）、額外用量、花費上限、金額欄位：有值或已啟用才出現在看板
- [x] 週窗口的用量去向與起訖時間帶進看板（供展開模式使用）
- [x] 以縫 ① 的測試涵蓋 spec〈測試決策〉列出的對應情境
