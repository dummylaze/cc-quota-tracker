# 21: 路徑解析與設定檔

**What to build:** 架設者的 Claude Code 目錄不在預設位置（用 `CLAUDE_CONFIG_DIR` 搬走），或想把納管目錄放在別處時，工具仍然讀對、寫對位置。第一次啟動會寫出一份完整的設定檔，路徑可以在裡面指定；命令列的 add／remove／list 與日後的 GUI 使用同一套路徑解析（ADR-0008）。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 實作前先實測並記錄：設了 `CLAUDE_CONFIG_DIR` 之後，Claude Code 的額度快取（平常在 home 底下的 `.claude.json`）與當前憑證實際寫在哪裡；結論寫回 spec〈路徑與設定檔〉
- [ ] 實作前與使用者確認測試縫：核心目前只接收 home 目錄與時鐘，路徑解析要從哪一道縫觀察
- [ ] 第一次啟動時，在 ADR-0008 指定的位置寫出完整設定檔：六項偏好都填上預設值、兩個路徑欄位寫 `null`；已存在的設定檔不覆寫
- [ ] Claude Code 目錄依序取第一個有值的：設定檔欄位 → `CLAUDE_CONFIG_DIR` → home 預設
- [ ] 納管目錄依序取第一個有值的：設定檔欄位 → home 預設
- [ ] 路徑欄位缺少或為 `null` 視為沒填；有填但目錄不存在時直接報錯、不回退，錯誤訊息指出是哪一個欄位
- [ ] 設定檔整個不是合法 JSON 時，兩個路徑都當成沒填，並提示設定檔無法讀取；不覆寫該檔
- [ ] 三層都沒指定、home 預設位置也找不到額度快取時，看板帶出「可能讀錯位置」的提示，不能只當成尚無讀數
- [ ] 路徑只在啟動時解析；執行中設定檔的路徑欄位改了，看板提示需重新啟動
- [ ] 命令列 add／remove／list 改用解析後的路徑；納管目錄搬到別處後，權限收緊照樣執行（ADR-0007）
- [ ] 永不寫入解析出的 Claude Code 目錄底下任何檔案
