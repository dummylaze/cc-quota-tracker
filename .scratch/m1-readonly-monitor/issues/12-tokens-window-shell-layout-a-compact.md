# 12: 設計 token、視窗骨架與版面 A 精簡模式

**What to build:** 一個可用的懸浮視窗：無邊框圓角、可拖動、可置頂，啟動時不跳主控台，精簡模式顯示使用中帳號的工作階段窗口與週窗口。所有顏色、字型、字級、圓角、間距集中在一處設計 token，版面只引用它。這一票也建立畫面層的物件生命週期紀律與縫 ② 的 item 數量測試。UI 原型只作視覺參考，不可直接沿用，要依生命週期規則重寫。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 視窗：圓角（透明色鍵挖出，Windows 10 適用）、無邊框、拖動任何位置可移動、置頂預設開啟、以 `pythonw` 啟動不出現主控台、開啟 DPI 感知
- [ ] 版面 A 精簡模式只顯示使用中帳號那一張卡：進度條、重置倒數與絕對時間、讀數年齡、憑證到期倒數（格式見 spec〈核心與看板〉的倒數格式）；「無計時中窗口」不顯示 0%
- [ ] 設計 token 兩套主題的顏色、字型、字級、圓角、間距集中一處；版面不寫死數值
- [ ] 只用標準庫與純 tk、Canvas，不用 ttk、不用 Pillow
- [ ] 每輪只更新既有 widget／item 的屬性，不建立新物件；必須建立的物件有銷毀路徑；`after()` 不重複註冊，`StringVar` 不累積
- [ ] 畫面層只渲染看板，不含判斷邏輯；文案先以單一語言暫置，語系抽換在後續票
- [ ] 縫 ②：同一個 widget 連續渲染 N 次看板，`len(canvas.find_all())` 每次回到同一狀態時相同
- [ ] 進度條顏色跟看板給的嚴重度走
