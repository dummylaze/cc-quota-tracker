# 06: 納管、匯入、移除搬進納管目錄 module

**What to build:** 「納管一份憑證快照」成為 module 的單一領域操作：檢查帳號標籤的合法性（不能用作檔名的字元、Windows 保留名稱）、替換前驗證憑證讀得出憑證指紋、收緊權限並事後驗證，回報是否修正過既有權限、是否未綁定；命令列 `add`、GUI 納管與匯入憑證檔都走它。「移除一個帳號標籤的憑證快照」也由 module 提供。票 01 的保護行為（綁定檔讀不到時納管與匯入整個拒絕、移除時不寫綁定檔、有快照讀不出憑證指紋時只加入新綁定）改由 module 承接。完成後核心不再持有任何納管目錄的路徑或檔案細節。

**Blocked by:** `05-accounts-and-binding-maintenance.md`

**Status:** ready-for-agent

- [ ] 帳號標籤的合法性檢查與憑證快照的檔名規則放在 module 同一處
- [ ] 命令列輸出、GUI 對話框、錯誤訊息與警告（含帳號標籤像 email 的提示）與重構前完全相同
- [ ] 票 01 新增的縫 ① 測試照樣通過，未修改
- [ ] 縫 ④ 測試：綁定檔被鎖住時納管被拒絕，憑證快照、綁定檔、讀數檔位元組都不變；移除照常刪快照、不寫綁定檔
- [ ] 縫 ④ 測試：寫入的憑證讀不出憑證指紋時，既有憑證快照維持原樣
- [ ] 納管帳號的 Windows 實際權限斷言（新目錄與新檔案、修正既有外露權限）照舊通過
- [ ] module 的說明寫明各檔案的寫入規則與失敗處理，以及已知限制：GUI 與命令列同時寫綁定檔時沒有跨程序的鎖，後寫的蓋掉先寫的；被蓋掉的使用中帳號綁定會由之後的 poll 補學
- [ ] 核心只剩 poll 編排、額度快取讀取、設定檔重讀、帳號身分與切換的判定、看板組裝；不再引用納管目錄內的檔名或子目錄名
- [ ] 既有縫 ① 測試一行未改、全部通過
