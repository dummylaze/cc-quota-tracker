# 09: 看板的「權限無法收緊」告警可以關掉，並在 README 說明

**What to build:** 使用者可以從右鍵選單關掉看板上的「權限無法收緊」橫幅；換位置或權限恢復後告警重新出現。README 兩語版說明這類位置的行為。行為依 ADR-0008 的 Consequences。

**Blocked by:** `08-untightened-warning.md`

**Status:** ready-for-agent

- [ ] 右鍵選單只在告警亮著時多出一項「不再提醒權限未收緊」（英文版同義）；已關掉時不出現
- [ ] 關掉的紀錄存在納管目錄的工具狀態裡，重新啟動後仍然有效
- [ ] 換到另一個納管目錄時告警重新出現（新目錄沒有關掉的紀錄）
- [ ] 同一個目錄某一輪權限全部收緊成功時，清掉關掉的紀錄；之後再收不緊，告警重新出現
- [ ] 關掉看板告警不影響 `add`／匯入的納管告警，兩者照樣告警
- [ ] 寫不進關掉的紀錄時，這次照樣把橫幅藏起來，下一輪重試寫入（與其他工具狀態的失敗處理一致）
- [ ] README 與 README.zh-TW 的納管目錄段說明：FAT32／exFAT（常見於隨身碟）無法收緊權限，工具照常運作並持續告警，告警可以從右鍵選單關掉；並加註「已經在 NTFS 上仍出現告警時，請確認這個目錄的擁有者是你」。兩版同一次編輯一起改
