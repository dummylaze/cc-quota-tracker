# 09: 看板的「權限無法收緊」告警可以關掉，並在 README 說明

**What to build:** 使用者可以從右鍵選單關掉看板上的「權限無法收緊」橫幅；換位置或權限恢復後告警重新出現。README 兩語版說明這類位置的行為。行為依 ADR-0008 的 Consequences。

**Blocked by:** `08-untightened-warning.md`

**Status:** resolved

- [x] 右鍵選單只在告警亮著時多出一項「不再提醒權限未收緊」（英文版同義）；已關掉時不出現
- [x] 關掉的紀錄存在納管目錄的工具狀態裡，重新啟動後仍然有效
- [x] 換到另一個納管目錄時告警重新出現（新目錄沒有關掉的紀錄）
- [x] 同一個目錄某一輪權限全部收緊成功時，清掉關掉的紀錄；之後再收不緊，告警重新出現
- [x] 關掉看板告警不影響 `add`／匯入的納管告警，兩者照樣告警
- [x] 寫不進關掉的紀錄時，這次照樣把橫幅藏起來，下一輪重試寫入（與其他工具狀態的失敗處理一致）
- [x] README 與 README.zh-TW 的納管目錄段說明：FAT32／exFAT（常見於隨身碟）無法收緊權限，工具照常運作並持續告警，告警可以從右鍵選單關掉；並加註「已經在 NTFS 上仍出現告警時，請確認這個目錄的擁有者是你」。兩版同一次編輯一起改

## Comments

### 來源（2026-10-03）

由 `02-non-acl-filesystem.md` 的 grilling 決定；告警本身在 `08-untightened-warning.md`。

### 實作（2026-10-03）

- 選單項放在「開啟納管目錄」之後；英文文案為 "Stop warning about unrestricted permissions"（開工前與使用者確認）。
- 關掉的紀錄存在 `.state/warnings.json`。「某一輪全部收緊成功」指這一輪有檢查過權限、且沒有一次收不緊；完全沒檢查權限的一輪不清紀錄。
- 讀不到紀錄時當成沒關，下次再讀。清除紀錄寫不進去時，磁碟上仍是「已關掉」，下一輪重試；重試成功前重新啟動的話，告警會被藏到下一次收緊成功為止。
- README 的說明放在兩版〈權限／Permissions〉小節。
