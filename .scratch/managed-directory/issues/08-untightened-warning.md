# 08: 收不緊權限時照常寫入，看板與納管發出告警

**What to build:** 納管目錄在收不緊權限的位置（FAT32／exFAT：寫入權限不報錯、查回仍未收緊）時，工具照常運作，不再讓寫入失敗；看板以橫幅、`add`／匯入以納管告警告知使用者，`check` 印出權限狀態。行為依 ADR-0008 的 Consequences。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 收緊後事後驗證仍不符時，不丟例外，寫入照常完成；`make_private` 本身回報錯誤時（例如 NTFS 上不是擁有者）也走同一條路
- [ ] 這類位置上切換紀錄與最後運作時間照常寫入，不再靜默停寫（ADR-0003）
- [ ] 這類位置上記住待命讀數照常寫入，讀數有變化的那一輪 poll 不再失敗
- [ ] 判定以行為為準：一輪 poll 中只要有一次收緊後查回仍未收緊，看板就帶「未收緊」狀態；下一輪全部收緊成功就熄滅。不查檔案系統的種類
- [ ] 看板以橫幅顯示（三種版面共用），文案：「納管目錄的權限無法收緊。把它搬到 NTFS 磁碟（一般的 C:、D: 槽）即可解除。」英文版同義
- [ ] `add` 與匯入新增一種納管告警，文案同上；命令列印到 stderr、結束碼 0（憑證快照已存入），GUI 列在完成對話框裡，與既有告警同一框
- [ ] 命令列 `add` 在這類位置不再印出 traceback
- [ ] `check` 多印一行納管目錄的權限狀態：已收緊／未收緊／尚未建立。只查不改，不嘗試收緊；「未收緊」不區分原因
- [ ] 視窗位置在這類位置上也照常寫入，與其他工具狀態一致（取代票 07「收不緊時這次沒記住」的行為；票 07 已 resolved，不回頭改它）
- [ ] 以縫 ① 模擬「收緊成功但沒效果」與「收緊回報錯誤」兩種，涵蓋上述每一條
