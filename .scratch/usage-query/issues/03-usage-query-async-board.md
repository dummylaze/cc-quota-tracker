# 03: 非同步查詢、冷卻與看板的查詢狀態

**What to build:** 核心提供不阻塞的查詢入口，供 GUI 使用：觸發後立刻返回，poll 只檢查子行程狀態，視窗不凍結。看板新增查詢狀態：進行中、冷卻中（手動查詢完成後 30 秒）、最後一次失敗的原因。進行中與冷卻中不能再次觸發；失敗不清空原本的讀數。查詢進行中發生切換時，查回來的讀數依額度快取裡的帳號識別碼歸屬，不會算到錯的帳號。查詢狀態只存在記憶體。畫面層在本票不動。

**Blocked by:** `01-usage-query-core.md`

**Status:** ready-for-agent

- [ ] 縫 ① 測試：觸發後看板立即顯示進行中、poll 不等待子行程；結束後看板顯示成功的新讀數、落後清除
- [ ] 冷卻期間再次觸發被拒絕，FakeClock 推進過冷卻後可以再查
