# 04: 單價表與估算金額

**What to build:** 報表依內建單價表估算金額。單價表隨版本發佈、執行時不連網（ADR-0013）；單價表沒有的模型照樣計入 token，金額標為未知。

**Blocked by:** 02

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 單價表是隨版本發佈的資料檔，記有版本日期；每個模型有 input、output、cache 寫入（5 分鐘、1 小時）、cache 讀取的單價，來源是供應商公開的定價
- [ ] 金額在產生報表時用當下的單價表計算，不寫進任何紀錄
- [ ] 單價表沒有的模型、或紀錄裡出現單價表無法計價的計費因素時，那部分金額記為未知：格子顯示「—」並附原因，合計標示含未知部分，頁首出現示警
- [ ] 報表頁首顯示單價表的版本日期，並標明金額是估算
- [ ] 打包好的 exe 帶有單價表，解壓縮後的命令列 exe 產生的報表有金額
- [ ] 測試走命令列 `report --no-open`、跑在假 home 上，用測試專用的假單價表
- [ ] 既有測試全部通過
