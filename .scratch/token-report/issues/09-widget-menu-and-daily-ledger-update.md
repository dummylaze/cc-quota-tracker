# 09: 懸浮視窗選單「token 報表」與每日帳本更新

**What to build:** 使用者從懸浮視窗的右鍵選單點「token 報表」，本工具在背景產生報表並用預設瀏覽器打開。懸浮視窗啟動後、以及之後每 24 小時，在背景啟動一次只更新帳本的子行程，使用者不必記得開報表也不會漏掉用量。

**Blocked by:** 03

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 右鍵選單新增「token 報表」：在背景啟動子行程產生報表，完成後用預設瀏覽器打開
- [ ] 懸浮視窗啟動後，以及之後每 24 小時，啟動一次只更新帳本的子行程
- [ ] 子行程不顯示主控台：exe 版呼叫命令列的 exe，原始碼版呼叫 `python -m`
- [ ] 子行程失敗只寫進錯誤紀錄，懸浮視窗不跳任何提示
- [ ] 選單開報表與每日更新同時發生時，兩者都能完成（帳本的單一寫入在 03）
- [ ] 解析在子行程裡跑，懸浮視窗行程的記憶體不因報表增加
- [ ] 測試以假的子行程取代，驗證選單項目、啟動時機與參數；前例是既有懸浮視窗查詢額度的測試
- [ ] 既有測試全部通過
