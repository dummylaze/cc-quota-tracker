# 08: 報表分頁「帳號比較」

**What to build:** 報表多一個分頁「帳號比較」：每個帳號一欄並排，全部帳號合計在最前，未歸屬單獨一欄、不分給任何帳號。每欄有總 token、占比、小長條圖、命中比例、cache 寫入與讀取、估算金額，各模型與其他欄位收在摺疊區。版面參考原型 `?variant=C`，以 spec 為準。

**Blocked by:** 07

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 每個有用量的帳號一欄；全部帳號合計在最前；有未歸屬用量時，未歸屬單獨一欄
- [ ] 每欄：總 token、占最大帳號的比例、區間內每日的小長條圖、cache 命中比例、cache 寫入、cache 讀取、估算金額
- [ ] 各模型與 input、output 收在每欄的摺疊區
- [ ] 跟其他分頁共用區間選擇；單看或合計的選擇在這個分頁不作用，畫面上看得出來
- [ ] 窄視窗時欄位改為換行排列，不出現整頁橫向捲動
- [ ] 淺色、深色兩種主題都正確
- [ ] 審美驗證（對比度、留白、高彩度面積等量測，兩種主題）達標
- [ ] 既有測試全部通過
