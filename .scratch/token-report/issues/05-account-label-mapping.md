# 05: 帳號標籤對照

**What to build:** 憑證快照移除後，綁定跟著清掉，歷史用量會查不到帳號標籤。報表另外保存一份「帳號識別碼 → 最後用過的帳號標籤」，讓已移除的帳號仍以原標籤顯示；從沒納管過的帳號依首次出現的順序編成「未監看帳號 n」，編號固定。

**Blocked by:** 02

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 每次產生報表時依現有的綁定更新對照；憑證快照移除後，該帳號的歷史用量仍顯示最後用過的帳號標籤
- [ ] 改了帳號標籤後，該帳號的歷史用量改用新標籤，不拆成兩個帳號
- [ ] 從沒有綁定過的帳號識別碼，依首次出現的順序顯示為「未監看帳號 n」；之後再產生報表，編號不變
- [ ] 對照含帳號識別碼，放在納管目錄的工具狀態裡，收緊權限的方式比照切換紀錄；報表 HTML 裡只出現帳號標籤
- [ ] 測試走命令列 `report --no-open`、跑在假 home 上，涵蓋移除、改名、未監看帳號的編號穩定
- [ ] 既有測試全部通過
