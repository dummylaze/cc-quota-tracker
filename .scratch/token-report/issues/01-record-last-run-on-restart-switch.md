# 01: 重新啟動後偵測到的切換記下上一次運作時間

**What to build:** 本工具停止運作期間發生的切換，要等重新啟動才會被記下，這段停機期間的用量不知道屬於哪個帳號。從這張票起，重新啟動後第一輪就偵測到的切換，切換紀錄另外記下本工具上一次運作的時間，報表才能把那段標為未歸屬時段。這張票不依賴報表的其他部分，要盡早發佈：每晚一天上線，就多一天的停機時段無從辨識。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 重新啟動後第一次完成判定的那一輪偵測到切換時，該筆切換紀錄帶上一次運作時間，取自上一輪觀測裡的最後運作時間（讀不到當前憑證或上一輪觀測、因而沒有判定的輪次不算）
- [ ] 執行中（不是重新啟動後第一次判定）偵測到的切換不帶這個欄位
- [ ] 第一次運作（沒有上一輪觀測）照舊算一次切換，不帶這個欄位
- [ ] 上一輪觀測沒有最後運作時間、或讀不懂時，照常記切換、不帶這個欄位
- [ ] 重新啟動後沒偵測到切換時，照舊不寫任何切換紀錄
- [ ] 舊格式的切換紀錄與上一輪觀測照舊可讀；寫不成時下一輪重試的行為不變
- [ ] 測試經過 poll、跑在假 home 上，涵蓋上述各情形
- [ ] 既有測試全部通過
- [ ] 結案後提醒使用者發版
