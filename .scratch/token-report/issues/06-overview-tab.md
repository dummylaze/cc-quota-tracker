# 06: 報表分頁「總覽」

**What to build:** 報表換成正式的分頁畫面，第一個分頁是總覽：使用者一眼看到區間內的總 token、cache 命中比例、估算金額，每日長條圖依帳號分色堆疊，下方是各模型的表。分頁框架與共用控制（區間、單看或合計）也在這張建好，07、08 接著加分頁。版面參考原型（本機分支 `prototype/token-report` 的 `?variant=A`），以 spec 為準。

**Blocked by:** 02, 04

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 實作前與使用者確認：分頁名稱的字樣、帳號的配色、數字在哪個量級換單位
- [ ] 分頁框架：頁首放產生時間、示警橫幅、區間選擇（近 7 天、近 30 天、全部）、單看某個帳號或全部帳號合計；切換分頁時保留選擇
- [ ] 三個總數：總 token（附 cache 讀取與寫入）、cache 命中比例（附算法）、估算金額（含未知部分時標示）
- [ ] 每日長條圖：合計時依帳號分色堆疊，未歸屬也是一段；單看一個帳號時不堆疊，只用該帳號的顏色；每段有完整數值的提示
- [ ] 各模型的表：合計 token、cache 寫入、cache 讀取、命中比例、金額；input、output 等其他欄位可以展開
- [ ] 顏色只代表帳號，不拿來表示模型或其他意義
- [ ] 數字格式：正體中文用萬、億，英文用 K、M、B；完整數值放在滑鼠停留提示裡
- [ ] 淺色、深色兩種主題都正確，跟著系統設定
- [ ] 審美驗證（對比度、留白、高彩度面積等量測，兩種主題）達標
- [ ] 計算邏輯的既有測試不受版面影響，全部通過
