# 03: 用量帳本

**What to build:** 報表的資料來源改成用量帳本：把對話紀錄算出的 token 數依「UTC 小時 × 帳號識別碼（或未歸屬）× 模型」追加存下，Claude Code 刪掉舊的對話紀錄之後，那段用量仍然看得到。另提供一個只更新帳本、不產生 HTML 的參數，給懸浮視窗的每日更新用（09）。

**Blocked by:** 02

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 帳本只存 token 數（各種類），不存金額；只追加、不改寫
- [ ] 只追加已經過去 24 小時以上、帳本裡還沒有的小時；最近 24 小時每次產生報表時從對話紀錄重新計算，不寫進帳本
- [ ] 報表由帳本加上最近 24 小時產生；對話紀錄被刪掉後，已入帳的用量照樣出現在報表
- [ ] 帳本記下最早有資料的時間與最後更新時間（失敗時含原因），報表頁首顯示兩者
- [ ] 帳本放在納管目錄的工具狀態裡，收緊權限的方式比照切換紀錄
- [ ] 同一時間只讓一個行程寫帳本；另一個等它寫完或跳過這次追加，報表照樣產生
- [ ] 不寫進說明的參數：只更新帳本、不產生 HTML；失敗時寫進錯誤紀錄並以結束代碼表示
- [ ] 測試走命令列、跑在假 home 上，涵蓋 24 小時邊界、跨 UTC 日界、刪除對話紀錄後仍保留、兩個行程同時寫入
- [ ] 既有測試全部通過
