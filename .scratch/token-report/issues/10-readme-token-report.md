# 10: README：token 報表

**What to build:** 架設者與使用者能從 README 讀到 token 報表怎麼打開、數字從哪裡來、帳本放在哪裡、未歸屬是什麼意思、金額只是估算。英文與正體中文兩版在同一次編輯一起改。

**Blocked by:** 08, 09

**Status:** resolved

## Acceptance criteria

- [x] 入口：右鍵選單「token 報表」與命令列 `report`、`report --no-open`
- [x] 資料來源：Claude Code 的對話紀錄；本工具每天把用量記進用量帳本，Claude Code 刪掉舊紀錄後仍保留；帳本與報表 HTML 各放在哪裡
- [x] 未歸屬時段的意思，以及切換紀錄開始之前、開始記錄上一次運作時間之前的限制
- [x] cache 命中比例的算法；金額依內建單價表估算、可能過時，未知模型不計金額
- [x] 報表不連網、不需要另外安裝任何東西
- [x] 兩版 README 的「不做」清單移除「token 報表」（目前正體中文版在 `README.zh-TW.md` 的不做清單、英文版在對應處），並檢查其他處有沒有仍寫成「尚未提供」的說法
- [x] 英文與正體中文兩版內容一致，既有的 README 檢查測試通過

## Comments
- 2026-10-23：**實作完成**。兩版 README 新增一章〈Token report〉／〈token 報表〉（放在〈Query usage〉之後、〈Credentials expire〉之前），另在功能清單、命令列清單、右鍵選單清單各加一行，〈For hosts〉末段的「供日後的報表」改連到新章，〈Out of scope〉移除 token 報表。章內涵蓋：入口與結束代碼、資料來源與帳本每日更新、帳本與報表 HTML 的位置（含帳號識別碼的權限差異）、歸屬規則與未歸屬三種情形、停機時段註記的限制、cache 命中比例算法、金額只是估算、不連網不需安裝。兩版逐段對照一致，標題層級一致。
- 票面外、實作時自補的決定（審查者逐條判斷過，皆認為合理）：

  - 〈For hosts〉首段「所有用量數字」改成「所有額度數字」，並補一句 token 報表讀的是對話紀錄、結構同樣未公開。
