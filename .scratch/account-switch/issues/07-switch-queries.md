# 07: 切換前後替舊帳號、新帳號查詢額度

**What to build:** 切換前先替舊帳號查一次額度，讓它變成待命帳號之後留下的讀數是新的；寫入之後立刻替新帳號查一次額度，讓新帳號的讀數馬上出現，同時確認切換真的生效。結果值多出「已寫入但驗證失敗」，以及「舊帳號查詢有沒有失敗」。命令列遇到驗證失敗時，結束代碼是 3。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 寫入前替舊帳號查詢額度；讀數沒有落後、或舊帳號沒有綁定時跳過
- [ ] 舊帳號查詢失敗不影響切換，結果值會標出這件事；命令列與 GUI 都不另外提示
- [ ] 寫入後替新帳號查詢額度；失敗 → 結果值是「已寫入但驗證失敗」，命令列印出訊息、結束代碼 3
- [ ] 切換觸發的兩次查詢都不啟動手動查詢的冷卻：切換後可以立刻手動查詢
- [ ] 切換觸發的查詢算進自動查詢的間隔（ADR-0010 修訂段）
- [ ] 額度查詢仍然是請 Claude Code 代查，本工具不發出網路請求
