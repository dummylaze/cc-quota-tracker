# 05: 寫回失敗重試與卡片提示

**What to build:** 憑證同步寫回快照失敗時，該帳號暫時是僅監看帳號，卡片顯示「寫回快照失敗，自動重試 n/3」。之後每輪 poll 重試一次：成功就自動恢復成納管帳號；3 次都失敗就停止重試，改成提示重新納管。下一次 Claude Code 又刷新（當前憑證的指紋改變）時，重試次數重新計算。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 寫回失敗 → 該帳號是僅監看帳號，原因是「寫回失敗（重試中 n/3）」，卡片顯示「寫回快照失敗，自動重試 n/3」（中英文語系）
- [ ] 每輪 poll 最多重試一次；重試成功 → 恢復成納管帳號，不需要使用者做任何事
- [ ] 3 次都失敗 → 停止重試，原因改成「寫回失敗（已停止重試）」，卡片提示重新納管
- [ ] 重試次數在重新啟動之後仍然記得；當前憑證的指紋改變時重新計算
- [ ] `list` 的原因同樣反映重試中與已停止重試
- [ ] 寫回失敗不影響看板的其他部分，也不跳對話框

## Comments

### 來自 03（2026-10-06）

僅監看帳號在卡片上統一是一條「僅監看帳號（{原因}）：在 Claude Code 登入這個帳號後重新納管」（`note.watch_only`），原因字樣由 `fmt.watch_only_reason` 對照 `watch_only.reason.*`；色點在 `canvas_text.notes()` 依原因分支，目前只有「沒有帳號資訊」用 sub，其他都是 critical（`03-watch-only-on-cards.md`）。本票新增寫回失敗的兩種原因時要決定：卡片的「寫回快照失敗，自動重試 n/3」是取代這一條的字樣、還是只當原因套進去；重試中（自動會好、不需使用者動手）的補救句也不適用「重新納管」。
