## Agent Brief

**Category:** enhancement
**Summary:** 提供 PyInstaller 打包的 Windows 版本（視窗、命令列兩個 exe，以 zip 發佈到 GitHub Releases），並加上版本號

**Current behavior:**
只能以原始碼部署：要裝 Python 3.9 以上，以 `pythonw -m cc_quota_tracker gui` 開視窗、`python -m cc_quota_tracker <命令>` 下指令。沒有版本號。開機自動啟動在登錄 `Run` 機碼的 `cc-quota-tracker` 值寫入「pythonw 加上把專案根目錄放進 `sys.path` 再呼叫 `main(['gui'])`」的命令；`RegistryAutostart.is_enabled()` 以整條命令比對，不一致就顯示成關閉。

**Desired behavior:**
- **版本**：套件提供 `__version__` 常數，是版本號的唯一來源，起始值 `1.0.0`。
  - `--version`：印出 `cc-quota-tracker 1.0.0` 到 stdout，結束代碼 0；原始碼版與 exe 版都支援，`--help` 的用法一併列出。
  - 右鍵選單最底部有一個灰色、不能點的項目，文字為 `cc-quota-tracker 1.0.0`（不分語系、換語系時不變）。
- **兩個 exe，同一個資料夾**（PyInstaller 資料夾模式，不用單一檔案模式）：
  - `cc-quota-tracker.exe`：視窗程式，不開主控台；不帶參數就開視窗（等同 `gui`）。
  - `cc-quota-tracker-cli.exe`：主控台程式，命令與參數、輸出、結束代碼都跟 `python -m cc_quota_tracker` 相同。
- **開機自動啟動**：在 exe 版打開時，寫入同一個登錄值名稱，命令為加引號的視窗 exe 完整路徑；原始碼版維持現有命令。看到另一種部署的命令時顯示為關閉，不做遷移。
- **建置相依**：PyInstaller 只列在建置用的 requirements 檔，鎖定確切版本並附 hash（`pip install --require-hashes`）；執行期仍然不依賴任何 pip 套件（ADR-0004）。
- **發佈 workflow**（GitHub Actions，推 `v*` tag 時觸發，Windows runner、Python 3.12）：依序跑完整測試 → 檢查 tag 去掉 `v` 之後等於 `__version__` → 建置 → 執行 `cc-quota-tracker-cli.exe --version` 並確認輸出含該版本 → 把資料夾打包成 `cc-quota-tracker-<版本>-win64.zip`，連同 SHA-256 發到 Releases。任一步失敗就不發佈。
- **README 雙語**（`README.md`、`README.zh-TW.md` 同一次改）：
  - exe 裝法改為主要裝法：下載 zip、解壓縮、雙擊 `cc-quota-tracker.exe`；命令列範例改成 `cc-quota-tracker-cli <命令>`。
  - SmartScreen：第一次開啟按「其他資訊 → 仍要執行」，並說明 exe 沒有簽章的原因。
  - 被防毒軟體誤判：比對 Release 附的 SHA-256，或改用原始碼部署。
  - 〈升級〉：關掉視窗，解壓縮覆蓋同一個資料夾；從原始碼版換成 exe 時，先關掉舊視窗，再在 exe 版重新打開開機自動啟動。不會自動檢查更新。
  - 原始碼部署降為「給開發者」一小節，最低 Python 3.9 不變。
  - 〈目前版本的範圍外〉拿掉「打包成 exe」。

**Key interfaces:**
- `__version__`：新常數，`--version`、右鍵選單、workflow 都讀它。
- 命令列 `main(argv)`：接受 `--version`（與 `--help` 同層，不需要解析路徑）。
- `launch_command()`／`RegistryAutostart`：在凍結（打包）狀態下回傳視窗 exe 的路徑。
- PyInstaller 設定：產出上述兩個 exe 共用一個資料夾。

**Acceptance criteria:**
- [ ] `--version` 在原始碼版印出 `cc-quota-tracker <__version__>`、結束代碼 0，有測試
- [ ] 右鍵選單最底部有灰色、不能點的版本項目，換語系後文字不變，有測試
- [ ] 凍結狀態下開機自動啟動寫入的是加引號的視窗 exe 路徑；非凍結狀態維持現有命令，有測試
- [ ] 本機建置出兩個 exe：視窗 exe 雙擊不出現主控台、開出視窗；命令列 exe 的 `list`、`--version` 輸出與原始碼版相同
- [ ] 建置用 requirements 檔鎖定版本並附 hash，`pip install --require-hashes` 可以裝起來
- [ ] workflow：tag 與 `__version__` 不一致時失敗、不發佈；測試紅燈時不發佈
- [ ] 視窗 exe 在展開模式、顯示所有帳號卡片時量 Private Memory 與 WorkingSet，對照 ADR-0004 的上限回報實測數字（超過時回報，不當成不通過）

- [ ] **需要人做**：推第一個 tag `v1.0.0`，確認 Release 有 zip 與 SHA-256

**Out of scope:**

- 程式碼簽章、向微軟提交誤判申訴
- 安裝程式、開始選單捷徑、自動檢查更新
- 32 位元、macOS／Linux 的打包
