# token 報表自己解析對話紀錄，不用 ccusage；單價表隨版本發佈

token 報表要把用量歸屬到帳號，而對話紀錄不含帳號資訊，唯一的依據是切換紀錄的時間點（ADR-0003、ADR-0009）。所以必須逐筆拿每一則回應的時間去對切換紀錄，在切換的那一刻把用量切開。ccusage 只輸出彙總（按日、週、月、session、5 小時區塊），時間過濾也只到日期：一天切換好幾次就切不開；session 也切不開，因為執行中的 session 會跟著改用切換後的憑證（ADR-0011）。用它的話，逐筆解析還是得自己寫，它能省下的只有單價表的維護。

因此本工具用標準庫自己解析 Claude Code 的對話紀錄（去重、歸屬、加總），金額依一份隨版本發佈的單價表計算，單價表的來源是供應商公開的定價。執行時不連網，也不下載單價表；價格變了就發新版。

## Considered Options

- **呼叫 `ccusage --json` 取值**（原本的規劃）：歸屬做不出來；還要使用者另外安裝 Node，打包好的 exe 就不再是解壓縮即可使用（ADR-0012）；它的定價可能從網路更新，要另外確保離線執行。
- **執行時從供應商的定價頁抓單價**：違反不新增網路呼叫的原則（ADR-0001、ADR-0010），而且要解析網頁，頁面一改版就壞。

## Consequences

- 每出一個新模型或改價，就要更新單價表、發新版。單價表裡沒有的模型，報表照樣顯示 token 數，金額顯示為未知，不去猜。
- 對話紀錄的格式跟額度快取一樣，是未公開的內部結構，沒有相容性承諾。結構認不得時要明確告警，不能靜默算成 0。
- 同一則回應會在對話紀錄裡寫成多行，必須去重，否則用量會被重複計算。
