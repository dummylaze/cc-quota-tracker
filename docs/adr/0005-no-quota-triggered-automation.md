# 不提供任何以額度為觸發條件的自動化

本工具明文**不做**：額度用盡時自動切換、排程輪替帳號，或任何以額度為觸發條件的自動動作。切換（第二版起才有）一律手動，而且要二次確認。UI 文案只陳述狀態、不建議動作，例如不會出現「A 已用滿，切換到 B」。持有多個自費帳號本身不違反服務條款，但「用完一個換下一個來延長額度」可能被視為規避服務限制，本工具不替這種用法提供便利。

## Considered Options

- **做成可關閉的選配功能**：否決。同類工具多數把自動切換當主要賣點，本工具的定位是多帳號分流管理（例如工作／個人），不是延長額度。這一條是範圍邊界，不是「目前還沒做」。
