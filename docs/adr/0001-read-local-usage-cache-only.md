# 只讀本機額度快取，不打任何 API

Claude Code 已經把使用中帳號的額度用量快取在 `~/.claude.json`，所以本工具的用量讀數全部來自這份本機檔案：不發網路請求、不自行刷新 token、不帶任何偽裝的 User-Agent。這樣就沒有 429、沒有 token 外流的路徑，也不落入服務條款的灰色地帶；代價是讀數只在 Claude Code 自己更新快取時才會更新，待命帳號只能顯示最後一次觀測到的讀數。

## Considered Options

- **定時呼叫 `/api/oauth/usage` 並自行刷新 token**（原始構想）：能取得即時數字，但要自己管理每個帳號的 token 生命週期，還要承擔 429 與條款風險。
- **把 API 留作預設關閉的退階層**：否決。只要開關存在，「零 API 呼叫」就不再是本工具的性質，而是一個設定值。明文列為 non-goal。
- **自備 statusLine 腳本當第二資料源**：暫不做。它會佔用使用者唯一的 `statusLine` 設定；等本機快取的結構真的改版壞掉時再評估。

## Consequences

快取欄位是未公開的內部結構，沒有相容性承諾。結構變更時，工具顯示最後一次成功的讀數並標出橫幅，不會靜默地顯示 0%。
