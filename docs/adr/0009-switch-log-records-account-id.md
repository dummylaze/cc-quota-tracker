# 切換紀錄記帳號識別碼，不記帳號鍵

ADR-0003 決定從第一版就記下每一次切換，作為日後把用量歸屬到帳號的唯一依據。這份紀錄只追加、事後無法補寫，所以「切到哪個帳號」必須用不會變的值來記。帳號鍵由帳號標籤組成，而標籤就是憑證快照的檔名，使用者可以隨時改名；未納管帳號則根本沒有標籤。因此每筆記帳號識別碼：切到納管帳號時記它綁定的識別碼，切到未納管帳號時記 `oauthAccount` 的識別碼；兩者都拿不到時仍然追加一筆，帳號記為未知，這段時間在報表上標為未歸屬，不去猜。

## Considered Options

- **記帳號鍵**：最直覺。但改名後，同一個帳號在報表上會拆成兩個，舊的帳號鍵也不再對應到任何東西；切到未納管帳號時沒有值可記。
- **記帳號鍵加當時的憑證指紋，報表時再用綁定反查**：紀錄裡不出現識別碼。但報表要靠綁定還在，憑證快照一刪、綁定跟著清掉，這段歷史就查不回來了。

## Consequences

- 切換紀錄和 `bindings.json` 一樣含帳號識別碼。兩者都放在納管目錄裡，同樣收緊權限，都不會出現在畫面上。
- 憑證指紋改變、`oauthAccount` 仍是同一個帳號（憑證被輪替）不算切換，不寫紀錄。這一點沿用 ADR-0002，ADR-0011 維持不變。
