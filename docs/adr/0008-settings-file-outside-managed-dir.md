# 設定檔獨立於納管目錄；路徑三層取值，有填但目錄不存在時不回退

設定檔固定放在 `%APPDATA%\cc-quota-tracker\settings.json`，不放進納管目錄。原因是納管目錄的位置本身寫在設定檔裡：如果設定檔放在納管目錄裡，要先知道納管目錄在哪才讀得到設定檔。

Claude Code 檔案所在的來源路徑依序取第一個有值的：設定檔欄位 → `CLAUDE_CONFIG_DIR` → home 預設。多一層設定檔欄位，是因為開機自動啟動只會繼承 Windows 使用者層級的環境變數；只在 shell profile 裡設定 `CLAUDE_CONFIG_DIR` 的部署者，自動啟動時會讀到另一個位置。

路徑欄位缺少或為 `null` 時，往下一層找。有填、但目錄不存在時直接報錯，不回退：回退到 home 會讀到另一組帳號，而且畫面看起來一切正常。

## Considered Options

- **設定檔放在 `~/.cc-quota-tracker.json`**：風格上跟其他東西都放在 home 底下一致，但不符合 Windows 放應用程式設定的慣例。
- **設定檔放在程式旁邊（可攜式）**：程式裝在唯讀位置時寫不進去。
- **納管目錄只能用環境變數指定，設定檔放在納管目錄裡**：跟只用 `CLAUDE_CONFIG_DIR` 一樣，會遇到開機自動啟動拿不到環境變數的問題。
- **來源路徑只跟著 `CLAUDE_CONFIG_DIR` 走**：理由同上。

## Consequences

- 納管目錄可以搬到別處，憑證快照會跟著目錄走。ADR-0007 的權限收緊，不論目錄搬到哪裡都照樣執行。但如果搬到收不緊權限的位置（例如 FAT32／exFAT 隨身碟：寫入權限不報錯，但沒有效果），工具照常運作，看板與納管時發出告警。看板的告警可以由使用者關掉；換到別的納管目錄，或某一輪權限全部收緊成功之後，再收不緊時會重新出現。不採用「偵測到就拒絕使用」：會把憑證快照放到隨身碟上，通常是使用者刻意的選擇，拒絕只會逼他改用更不受控的手動複製。
- 改路徑要重新啟動才生效；偏好則在執行中就會重讀。
